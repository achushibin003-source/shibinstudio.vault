# 3D Thapas Portfolio Setup (GitHub + Vercel)

1. Extract this ZIP file on your phone.
2. Copy your `OM Special Duty.mp3` audio file into the exact same folder as `index.html`.
3. Upload both `index.html` and `OM Special Duty.mp3` to the root of your GitHub repository (`achusource003`).
4. Open your Vercel live site and tap anywhere on the screen to start the looping background music.
